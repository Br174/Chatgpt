SCOPE

PROJECT

CORE RULE
Meld is a source of candidate code improvements, never the installable application channel for MusicLab.
Do not install a Meld APK over MusicLab.
Do not replace MusicLab with Meld.
Do not overwrite MusicLab customizations blindly.

TRIGGER MODEL
Preferred trigger is the existing in-app Meld upstream notification.
When Bruno reports a Meld update, MotorLab must:
1. identify the new Meld tag/release;
2. compare accepted Meld baseline -> target Meld release;
3. produce exact changed files/commits/patch;
4. compare those changes against the current approved MusicLab source;
5. classify clean changes, logical hotspots, and real Git conflicts;
6. create/use a dedicated MusicLab LAB;
7. apply clean upstream changes exactly where safe;
8. resolve overlapping changes semantically while preserving approved MusicLab behavior;
9. build and run regression checks;
10. present material conflicts/choices to Bruno before promotion;
11. never promote to MADRE without Bruno real-device approval.

IMPORT POLICY
- Prefer exact Git merge/cherry-pick/patch semantics when history permits.
- MusicLab and Meld currently share Git ancestry, so exact upstream changes can be retained where compatible.
- Never reimplement an upstream change merely approximately when the exact patch is safely reusable.
- A clean Git merge does not prove semantic compatibility; logical conflict analysis remains mandatory.
- If both MusicLab and Meld modify the same behavior, preserve both when compatible; otherwise explain the alternatives before choosing.

MIGRATION NOTE
LAB/test APKs through LAB12/LAB13 were commonly signed with regenerated temporary debug keys and are not a valid permanent Android update identity.
The first move to it.verlezza.musiclab + permanent signing is a one-time migration/install. After that, future musiclab-v releases with the same applicationId and signing key can update in place.
Preserve user data through the application's backup/restore path or another explicitly tested migration method before removing an old differently-signed package.
