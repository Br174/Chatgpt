MOTORLAB SATELLITE SYNC V1

STATUS
Mandatory MotorLab synchronization capability.
Established: 2026-09-29.
Central authority: Br174/Chatgpt.

PURPOSE
Each registered project keeps a verified local MotorLab satellite while Br174/Chatgpt remains the single authoritative MotorLab source.

BOOT
1. Read project MOTORLAB_PROJECT_HOOK.txt.
2. Read .motorlab/MOTORLAB_SYNC_STATE.txt.
3. Read .motorlab/MOTORLAB_LOCAL_CORE.txt.
4. Verified local core is immediately available as fallback.
5. When central is reachable, read MOTORLAB_RELEASE_MANIFEST_V1.txt and compare local/central releases.

SAFE UPDATE
- pin a MotorLab release for the whole active operation;
- never update during active write/build/test/promotion/release;
- update only at safe boundary;
- preserve current verified local bundle as LAST_GOOD before adopting newer bundle;
- fetch MOTORLAB_SATELLITE_BUNDLE_V1.txt;
- validate release id and required markers;
- replace only MotorLab control-plane files;
- update sync state;
- re-read local files and verify before declaring success.

REQUIRED BUNDLE MARKERS
MOTORLAB_SATELLITE_BUNDLE
RELEASE=<id>
CENTRAL_AUTHORITY=Br174/Chatgpt
PROJECT_NATIVE_ENGINE_POLICY=coexist-preserve
CHANGE_COMPATIBILITY_GUARD=required
WATCHDOG=required
PREVENTIVE_WATCHDOG=required
MANUAL_LIGHTNING_RECOVERY=required
TWO_STRIKE_NO_PROGRESS=required
RESUME_RECOVERY=required
FOREGROUND_STALL_GUARD=required
PROGRESS_REPORTING=required
VISUAL_STATUS=required
SINGLE_WRITER=required
CHECKPOINT_RECOVERY=required

R4+ COMPATIBILITY REQUIREMENT
Bundle is invalid without CHANGE_COMPATIBILITY_GUARD=required. Every write-capable MotorLab/project change receives conflict/overlap/regression preflight before first write.

R5+ CONTINUITY REQUIREMENT
For release 2026.09.29-r5 and later, bundle is invalid unless all are present:
PREVENTIVE_WATCHDOG=required
MANUAL_LIGHTNING_RECOVERY=required
TWO_STRIKE_NO_PROGRESS=required
This guarantees local fallback retains preventive health checks, the manual `⚡` recovery shortcut and prohibition on a third identical no-progress recovery/write/retry attempt without new evidence.

ROLLBACK
If newer bundle cannot be verified, keep/restore LAST_GOOD, record safe failure, preserve project and report fallback.

CENTRAL UNAVAILABLE
Use previously VERIFIED local release. Do not invent update. Recheck at later safe cycle.

NO APP RUNTIME CHANGE
.motorlab is development/orchestration metadata and must not intentionally alter app code, UI, package identity, signing, native engines or runtime dependencies.

FUTURE PROJECTS
Future MotorLab software projects receive hook + local satellite files during onboarding when repository integration is available.

AUTOMATIC MEANING
Synchronization occurs when an execution cycle with repository access opens the project. Repository files cannot self-update while no executor/tool is running.
