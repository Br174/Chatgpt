PURPOSE
Track which project repositories are structurally connected to MotorLab and which contain the local-first synchronized satellite defined by MOTORLAB_RELEASE_MANIFEST_V1.txt and MOTORLAB_SATELLITE_SYNC_V1.txt.

GLOBAL PRINCIPLES
- MotorLab activation is implicit and persistent for recognized registered projects.
- MOTORLAB_PROJECT_HOOK.txt is the project identity/adapter entrypoint.
- .motorlab/MOTORLAB_LOCAL_CORE.txt provides immediate verified local activation/fallback.
- .motorlab/MOTORLAB_LOCAL_CORE_LAST_GOOD.txt provides rollback safety.
- .motorlab/MOTORLAB_SYNC_STATE.txt records local release and verification state.
- Br174/Chatgpt remains the only central authority; local satellites are synchronized mirrors, not forks.
- Project-native/domain engines are preserved and coexist with MotorLab.
- Visible session boot proof, verified progress reporting, Watchdog, Resume Recovery, checkpoint recovery, single-writer protection and fireworks-success reporting remain mandatory when applicable.
- MotorLab release changes occur only at safe boundaries, never in the middle of an active write/build/test/promotion operation.

VISIBLE BANNER REQUIREMENT

Do not append satellite, CORE, synchronization or native-engine wording unless reporting a real warning, recovery event or blocker.

HOST LIMITATION
A repository cannot force a context-free or completely frozen host/model to open a new execution cycle. A one-time persistent ChatGPT project/global instruction can expose the MotorLab entrypoint to every new chat. Once an execution cycle exists, local-first activation and safe synchronization apply automatically.

NEW PROJECTS
When a future software project becomes concrete and repository integration is available:
- register it in canonical routing/integration state;
- install MOTORLAB_PROJECT_HOOK.txt;
- install .motorlab/MOTORLAB_LOCAL_CORE.txt from the current canonical bundle;
- install an identical initial .motorlab/MOTORLAB_LOCAL_CORE_LAST_GOOD.txt;
- install .motorlab/MOTORLAB_SYNC_STATE.txt as VERIFIED for the current release;
- bind MOTORLAB_CORE_ENTRYPOINT_V1.txt, release manifest and sync protocol;
- preserve all project-native engines;
- require visible activation proof and all current MotorLab CORE protections.
