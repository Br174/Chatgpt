R15 RULES PRESERVED
- Initial change request is intent only; pre-change report + later Bruno approval precedes first write.
- For approved defect/regression work where Bruno expects APK/ZIP/testable artifact, default critical path is repair -> risk-appropriate verify -> artifact -> deliver.
- Safely deferrable causal/prevention work is persisted in POST_ARTIFACT_ROOT_CAUSE_QUEUE and continues afterward.
- Root Cause Closure remains mandatory; non-deferrable high-risk causes stay before artifact when needed for trust/safety/integrity.
- Delivered artifact/ref/checksum remains stable while Bruno tests it; later prevention builds are separate controlled states.
- Artifact progress may reach 100% while overall MotorLab progress remains below 100% until causal closure.
- Technical Change History remains provenance/search.
- Visible Registro Modifiche e Ripristini contains only specific Bruno-confirmed working modifications with one stable plain integer per feature family.
