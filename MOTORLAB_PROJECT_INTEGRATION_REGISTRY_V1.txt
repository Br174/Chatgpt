R13 CHANGE HISTORY RULE
- Every verified material Bruno-requested project change is indexed automatically when technically possible.
- Each record points to immutable Git provenance and semantic aliases Bruno may naturally use.
- Natural query such as "player" searches project registry before raw Git archaeology.
- Multiple materially different matches are disambiguated unless Bruno already identified one.
- Default restore is selective into a new isolated LAB from current proper baseline and preserves unrelated later work.
- Whole-version rollback is separate and requires explicit whole-version intent.
- Pre-r13 history is backfilled from verified Git/ledger evidence on demand and then persisted.
- Successful restore writes a new record with RESTORED_FROM provenance.
