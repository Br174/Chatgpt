R5+ ANTI-LOOP / WAKE
Watchdog remains sole health/intervention coordinator; Resume Recovery owns continuation; Foreground Stall Guard owns prevention; automatic recovery does not depend on `⚡`.

R6+ MANUAL LIGHTNING SAVE-THEN-RESUME

R7+ MONOTONIC RECOVERY FLOOR
Same-operation verified progress is monotonic by default. Stale lower checkpoints cannot silently override newer coherent verified progress. Regression requires material invalidation evidence and visible explanation.

R8+ PRE-RESPONSE BOOT GATE / PROJECT CONTINUITY
Registered project context or clear software-build intent activates MotorLab before substantive project work. Every registered project has a canonical Project Continuity ledger; new chats reconcile it with newer live repository/provider/job/artifact state and continue unfinished work without transfer prompts.

R10 numeric-progress rule:
- classic format remains `Progresso MotorLab: <N>%`;
- numeric percentage is a first-class high-presence signal during substantial work;
- once a verified progress value exists, every meaningful user-facing operational status should normally include the current N%, even if unchanged;
- repeated same percentage is correct when state changes without a newly verified milestone;
- no percentage is invented merely for visibility;
- numeric progress remains evidence-based, monotonic and governed by Progress Reporting/Recovery Floor;
- 💭 is high-level operational analysis only and must not expose private chain-of-thought;
- 🐢 slow-but-live and ⏳ legitimate external waiting are distinct from ⚡ actual recovery/health intervention;
- 🧪 and 🔄 indicate in-progress verification/synchronization and do not imply completion.
