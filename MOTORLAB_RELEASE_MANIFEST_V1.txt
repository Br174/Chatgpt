R5+ ANTI-LOOP / WAKE
Watchdog remains sole health/intervention coordinator; Resume Recovery owns continuation; Foreground Stall Guard owns prevention; automatic recovery does not depend on `⚡`.

R6+ MANUAL LIGHTNING SAVE-THEN-RESUME
Manual `⚡` performs bounded recoverable-state salvage first, then Watchdog classification and targeted continuation.

R7+ MONOTONIC RECOVERY FLOOR
Same-operation verified progress is monotonic by default. Stale lower checkpoints cannot silently override newer coherent verified progress. Regression requires material invalidation evidence and visible explanation.

R8+ PRE-RESPONSE BOOT GATE / PROJECT CONTINUITY
Registered project context or clear software-build intent activates MotorLab before substantive project work. Every registered project has a canonical Project Continuity ledger; new chats reconcile it with newer live repository/provider/job/artifact state and continue unfinished work without transfer prompts.

R9+ LABELED VISUAL STATUS
Every MotorLab status emoji shown to Bruno includes its canonical short Italian label beside it. 🎆 means a completed action/phase, while 💯 is reserved exclusively for full end-to-end requested completion after verification/delivery.

R10+ EXTENDED VISUAL STATUS + HIGH-PRESENCE NUMERIC PROGRESS
Canonical visual status additionally includes solution search, compatibility, slowness, elaboration, external wait, tests and sync states. Classic format remains `Progresso MotorLab: <N>%`; numeric progress is evidence-based and monotonic.

R11+ ROOT CAUSE CLOSURE + HARD PROGRESS VISIBILITY
Every real problem/anomaly receives immediate containment plus root-cause investigation. Manual alignment/symptom repair alone is not definitive closure. Causal status distinguishes confirmed cause/hypothesis/external/unknown; recurrence surfaces are checked proportionately. Control-plane-only activity cannot silently become a new LAB/MADRE/CANDIDATA. Numeric progress remains visible through substantial operations.

R12+ FAST ITERATION + NO-SPIN HANDOFF
MOTORLAB_FAST_ITERATION_NO_SPIN_V1.txt is mandatory. Verified persistent executor handoff must not leave foreground chat polling indefinitely; default unchanged provider probes max 2. Eligible LOW/MEDIUM isolated LAB correction loops use risk-scaled verification, while HIGH-risk and every CANDIDATA/MADRE promotion retain full applicable regression/lifecycle protections.

R13+ SEMANTIC CHANGE HISTORY + SELECTIVE EXACT RESTORE
For release 2026.09.30-r13 and later:
- MOTORLAB_CHANGE_HISTORY_REGISTRY_V1.txt is mandatory;
- each registered project receives a canonical project change registry pointer;
- every verified material Bruno-requested change is automatically indexed at a material verified boundary;
- records use ordinary semantic aliases plus immutable Git refs/commits/trees/files as exact provenance;
- queries such as "player" search the project registry before raw repository archaeology;
- multiple materially different matches are disambiguated by title/date/LAB/status unless Bruno already specified one;
- default restore is selective into a new isolated LAB from the current proper baseline, preserving unrelated later work;
- feature restore does not imply whole-project rollback;
- whole-version rollback remains available only when explicitly requested;
- composite changes must not replay unrelated subfeatures when a safe scoped source boundary exists;
- if historical work predates r13, verified Git/ledger backfill occurs on demand and is then persisted for future searches;
- restored changes create new registry records linking RESTORED_FROM;
- registry/control-plane metadata uses CI suppression/path filters and must not launch unrelated app builds;
- Change Compatibility Guard, Root Cause Closure, single-writer and lifecycle protections remain mandatory.
