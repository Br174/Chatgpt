VISIBLE STARTUP RULE
Normal activation proof is exactly:
"⚙️ MotorLab attivo"
For r8+, this is a mandatory PRE-RESPONSE first-line gate whenever a supported MotorLab activation path is visible.

R5+ ANTI-LOOP / WAKE
Watchdog remains sole health/intervention coordinator; Resume Recovery owns continuation; Foreground Stall Guard owns prevention; automatic recovery does not depend on `⚡`.

R6+ MANUAL LIGHTNING SAVE-THEN-RESUME
Manual `⚡` performs bounded recoverable-state salvage first, then Watchdog classification and targeted continuation. No heavy backup and no false hidden-reasoning snapshot claim.

R7+ MONOTONIC RECOVERY FLOOR
Same-operation verified progress is monotonic by default. Stale lower checkpoints cannot silently override newer coherent verified progress. Regression requires material invalidation evidence and visible explanation.

R8+ PRE-RESPONSE BOOT GATE
For release 2026.09.30-r8 and later:
- registered project context or clear software-build intent activates MotorLab before substantive project response/tool/write/build work;
- the first user-visible line is the normal MotorLab banner;
- short/administrative/"continua" messages do not bypass activation when project context is recognizable;
- activation prompts are fallback-only.

R8+ PROJECT CONTINUITY
For release 2026.09.30-r8 and later:
- every registered project has a canonical central Project Continuity ledger;
- new chats automatically load/reconcile that ledger with live repository/provider/job/artifact state;
- live newer evidence wins over stale ledger/history;
- same logical operation id, phase, progress floor, pending verification and next safe step survive chat changes;
- continuation-relevant material transitions write through to the ledger when safe;
- substantial turns flush continuity state before valid terminal/handoff states when technically possible;
- copied handoff prompts and conversational memory are auxiliary only;
- unfinished prior work routes through Resume Recovery/Watchdog before unrelated write-capable work;
- project-native/domain engines remain preserved.

STATE AUTHORITY ORDER

3. canonical Project Continuity ledger;
4. current checkpoint/pending ledger;
