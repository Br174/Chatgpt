UPDATE RULE
A project satellite compares its local RELEASE with CURRENT_RELEASE at a safe bootstrap boundary. If central is newer, synchronization follows MOTORLAB_SATELLITE_SYNC_V1.txt. Never replace the active local core in the middle of an active write/build/test/promotion operation.

ROLLBACK RULE
Before applying a newer satellite bundle, preserve the previously verified local core as LAST_GOOD. If validation of the new bundle fails, restore LAST_GOOD and report a visible MotorLab protection event.

NATIVE ENGINE RULE
Satellite synchronization must never overwrite project-native engines, application source, UI, package/signing identity, project adapters or lifecycle state. Only MotorLab control-plane files are synchronized.

VISIBLE STARTUP RULE
For release 2026.09.29-r2 and later until superseded, the normal visible activation banner is exactly:
"⚙️ MotorLab attivo"
Extra technical wording is reserved for actual warnings, recovery events or blockers.

FOREGROUND STALL RULE
For release 2026.09.29-r3 and later, MOTORLAB_FOREGROUND_STALL_GUARD_V1.txt is mandatory.
Before long/risky phases MotorLab must establish recoverable checkpoint/next-step state, prefer a real persistent executor for backgroundable work when available, and otherwise split ordinary-chat work into bounded recoverable segments. ChatGPT client "still processing" UI is not a MotorLab heartbeat. If host execution disappears, recovery occurs at the first later available cycle under Resume Recovery.

CHANGE COMPATIBILITY RULE
For release 2026.09.29-r4 and later, MOTORLAB_CHANGE_COMPATIBILITY_GUARD_V1.txt is mandatory before every write-capable MotorLab self-change and every write-capable change to a MotorLab-managed project.
The preflight must inspect current relevant state for conflicts, overlaps, duplicated responsibility, protected behavior, precedence ambiguity, blast radius, backward compatibility and regression risk. Overlaps must be merged or explicitly ordered/superseded; unresolved unsafe conflicts block the write.
This rule applies to all existing and future MotorLab projects.

FUTURE PROJECT RULE
Every future MotorLab software project must receive the satellite local files during onboarding when repository integration is technically available and use MOTORLAB_CORE_ENTRYPOINT_V1.txt as the canonical boot path. It inherits the Change Compatibility Guard automatically.
